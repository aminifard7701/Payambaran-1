# هزار سؤال و جواب درباره پیامبران

پروژه آغازین برنامه اندروید فارسی و راست‌چین، بر پایه PDF کتاب ارسالی.

## امکانات نسخه آغازین
- صفحه خانه و ناوبری فارسی
- پیوند به PDF اصلی کتاب
- جست‌وجو در پرسش‌های نمونه
- دسته‌بندی پایه
- آزمون چهارگزینه‌ای نمونه
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی

## نکته مهم
فایل `src/data/questions.js` فعلاً فقط چند سؤال نمونه برای بررسی رابط کاربری دارد؛ بانک کامل پرسش‌ها باید در مرحله بعد از PDF استخراج و بازبینی شود. APK امضا‌شده برای انتشار نیست؛ گردش‌کار خروجی debug APK می‌سازد.

## ساخت محلی
```bash
npm install
npm run build
npx cap add android
npx cap sync android
```
برای ساخت APK به Android SDK و Java نیاز است؛ مسیر GitHub Actions این کار را در فضای ابری انجام می‌دهد.
